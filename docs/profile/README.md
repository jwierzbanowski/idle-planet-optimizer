# Profile

The **Profile** modal holds your persistent game configuration: rooms, station levels, beacons, and managers. It is opened with the **Profile** button (user icon) in the top bar.

The Profile is the same across all playthroughs — it represents your upgrades, not the progress of a single run. The per-run state (projects, market, mining levels) lives in the [Game](../game.md) modal and the temporary [overrides](../reset.md).

## Tabs

The modal has four tabs, each documented on its own page:

| Tab | Contents | Page |
| --- | --- | --- |
| **Rooms** | Mine/smelt/craft speed, cost and value modifiers. | [Rooms](rooms.md) |
| **Station** | Mining, crafting, smelting, and alloy/item station levels. | [Station](station.md) |
| **Beacon** | Beacon levels per planet range. | [Beacon](beacon.md) |
| **Managers** | Manager cards with stars and skills. | [Managers](managers.md) |

## Common controls

- Most entries are adjusted with **− / +** steppers (hold `Ctrl`/`Shift` for bigger steps — see [keyboard shortcuts](../README.md)).
- The number in the middle shows the current level (and the max level, e.g. `5/60`).
- On the right, the **effect multiplier** updates live as you change levels.
- Everything you set here is saved automatically and reflected immediately in the tables and the [Multipliers bar](../multipliers.md).
