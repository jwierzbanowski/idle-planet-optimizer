# Tabs — Credits

The **Credits** tab shows the milestone reward values for each galaxy run. Use it to plan how far you need to push your galaxy to reach a specific credit goal.

## Columns

| Column | Meaning |
| --- | --- |
| **#** | Milestone number. |
| **Value** | Total galaxy value required to unlock this milestone. |
| **Credits** | Credits earned when you reach this value milestone. |
| **Cumul.** | Running total of credits from all milestones up to this point. |

## Run Value Goal

The input box at the top lets you enter a target galaxy value (e.g. `5T`). The tab highlights all milestones reachable at that value and displays the total credits you would earn.

## Milestones

Milestones start at **10M** galaxy value and follow a 10× pattern within each suffix tier:

| Tier | Values |
| --- | --- |
| M | 10M, 100M |
| B | 1B, 10B, 100B |
| T | 1T, 10T, 100T |
| q | 1q, 10q, 100q |
| Q | 1Q, 10Q, 100Q |
| s | 1s, 10s, 100s |
| S | 1S, 10S, 100S |
| O | 1O, 10O, 100O |
| N | 1N, 10N, 100N |
| D | 1D, 10D, 100D |

The credit reward for each milestone is the triangular number of the milestone × 10 (with the first nine milestones using the exact game values).
