# Reset

The **Reset playthrough** button (↺ icon) in the top bar clears the **temporary** data of the current playthrough. It asks for confirmation before doing anything.

## What reset clears

- **Projects** (the checkboxes in the [Game](game.md) modal)
- **Market overrides** (set in the [Supply & Demand panel](supply-and-demand.md))
- **Mining overrides** (mining levels, colonies, probes, rovers, ore targeting, alchemy)

## What reset keeps

- **Managers** and their stars/skills
- **Pinned items** in the Supply & Demand panel
- Your **Profile** (rooms, station, beacon)

## After a reset

A red dot badge appears on the **Game** button to remind you that the playthrough was cleared. Use it when you start a new run and want to plan from scratch — the manager and profile configuration stays intact, so you do not have to re-enter it.

> Export a [backup](backup.md) before resetting if you want to be able to restore the cleared state.
